# 未決事項・ゾーニング案 v1 の既知の課題

`plan/plan.json`（ゾーニング案 v1）は、要件を満たす配置を試したたたき台。`python tools/check_plan.py` で重なり・面積・動線をチェックできる。要件の隣接（動線）22項目はすべて満たしている。

## v0 からの変更
- LDK を幅16.5m×奥行3.0mの帯状から、9.8m×5.0m（30.2畳）に変更。家具を置ける形にした。
- 主寝室を北東から南東の角へ移動。北西のガレージと真の対角になった。
- 居住面積を 48.4坪 → 44.4坪 に圧縮（延床 57.4坪）。

## 設計上の課題
- **視線抜け**：玄関ホールの西面（中庭側）をガラスにしたが、玄関ドアの「正面」ではなく側面。家族玄関から SIC・土間ホールを抜けた先で中庭が見える形。
- **ゲスト動線**：ゲスト玄関から土間ホール（ガレージ勝手口と共用）を通って玄関ホール・LDKへ行く。ゲスト用と家族用の土間を分けるかどうか。
- **子ども部屋A と FCL**：FCL に直接面するのは子ども部屋Bだけ。Aへは可動間仕切りを開けるかLDK経由。
- **トイレ2**：主寝室から WIC・FCL を通って行く位置。主寝室から直接入れるかどうか。
- **中庭の奥行**：3.4mと浅く、南のLDKの屋根で冬は日が入りにくい。中庭を南北に広げて東西を詰める案もある。
- **未反映の設備**：EV用200V、局所第1種換気、乾太くん、スロップシンクは3Dに簡易的に置いただけで、仕様の検討はこれから。

## 要件に書かれていないので決める必要があるもの
- 敷地の形・方位・道路との関係（v1は「道路が北、西側に中庭が開く」と仮定）
- 屋根の形（v1は陸屋根＋太陽光パネル）、外壁（v1は白い塗り壁＋北面は焼杉調）
- 予算、時期、地域（耐震・断熱・補助金の判断に必要）
- 構造の選択（木造ラーメン構法か重量鉄骨造か）
- 外周の窓（v1は中庭側の大開口だけ。高窓・地窓は未配置）
