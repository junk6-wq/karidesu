## 1. 建築・基本諸元

| 項目 | 内容 |
| --- | --- |
| 構造種別 | 木造ラーメン構法（SE構法等）または重量鉄骨造（耐震等級3・許容応力度計算必須） |
| 延床面積 | 約58坪（居住スペース 約45.5坪 ＋ ビルトインガレージ 約12.5坪） |
| 中庭面積 | 約14畳（ウッドデッキ＋タイルテラス、延床面積外） |
| 基本思想 | 「外に閉じ、中に開く」コの字型コートハウス（完全カーテンレス生活） |

## 2. 部屋構成・各室スペック

### 2-1. ビルトインガレージ（並列2台）
- 寸法：幅6.8m × 奥行6.3m（大型ミニバン・レクサス・プレミアムEVが余裕で収まるサイズ）
- 中庭直結：ガレージ南面（中庭側）に全開口大型サッシを設置
- EV用200V充電コンセント、局所第1種換気扇、室内鑑賞用FIXガラス窓完備

### 2-2. LDK（約30畳）
- キッチン・ダイニング：横並び（ポポラート配置、ストレート配膳）
- 中庭フルオープン連動サッシ（フラットレール）
- ベンチヌック／半個室ワークスペース造作

### 2-3. 中庭（約14畳）
- ガレージ・LDKから直接出入り可能
- シンボルツリー、二重系統排水ドレン・オーバーフロー管敷設

### 2-4. 子ども部屋 A・B（各約4.5〜5.0畳）
- 可動間仕切りによる2ドア1ルーム仕様（幼少期は10畳、将来2部屋に分割）
- LDKを通ってアクセスするリビングアクセス動線

### 2-5. 主寝室（約7.5畳）＋ WIC（約3.5畳）
- ガレージから最も離れた対角線の最奥配置（早朝・深夜のエンジン音を完全遮断）

### 2-6. 水回りゾーン（完全分離・通り抜け動線）
- 独立幅広洗面化粧台
- 脱衣・ランドリールーム（室内物干しパイプ、乾太くん、スロップシンク）
- ウォークスルーFCL（ファミリークローゼット・約3.5畳）
- システムバス（1.25坪サイズ）

### 2-7. 玄関・収納・衛生
- 2WAY玄関（ゲスト用玄関 ＋ 家族用玄関／土間収納／SIC）
- ただいま手洗い
- 大容量パントリー（ガレージ勝手口・玄関直結）
- トイレ2箇所（玄関付近・主寝室付近）

## 3. 動線設計の要件（無駄な廊下ゼロ）

| 動線 | 内容 |
| --- | --- |
| 買い物動線 | ガレージ勝手口／家族玄関 → パントリー → キッチン直結 |
| 配膳動線 | キッチン横並びダイニングで配膳・下膳を横スライド数歩で完結 |
| 洗濯動線 | 脱衣ランドリー ⇄ ウォークスルーFCL ⇄ 各居室を直線移動で完結 |
| 視線抜け | 玄関ドア開放時に正面の中庭が視界に抜けるピクチャーウィンドウ |
